## Judgment calls

- **Resonant Overtone** keeps "an ally, itself included," which the current entry does not repeat: the section line above the Resonants ("All three react whenever a living ally, themselves included, casts a spell") says it, and its sibling descriptions Chorus and Adept (not in this slice) keep it. Only the sentences the rewrite changed moved.
- **Spider Broodwarden** and **Lullpollen Dozer** keep "It never applies Web / puts anything to Sleep itself; it only benefits from what its species-mates have done." The rewritten entries still carry it in the same place, so it is transcribed as the earlier text was; if the design agent reads it as a remark about the creature, it is a one-sentence cut.
- **Flickerling Wick**: "The burn is a **cost** (`spec/combat.md#damage-channels-and-the-additional`)." becomes "The burn is a cost." once the citation is stripped.
- **Unicorn Lightbearer**: "With Flurry it attacks twice, so it revives twice." is the entry's own sentence.
- **Sporch Igniter** / **Sporch Cinderlord**: the Burn numbers (35% of the applier's Intelligence, the 3-turn timer, the refresh rule) moved from the entries to `content/rotcap-hollow.md`'s Burn status section, so the descriptions no longer carry them.
