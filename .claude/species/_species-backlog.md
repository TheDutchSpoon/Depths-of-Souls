# Depths of Souls — Unused Concepts (inspiration backlog)

Species concepts surfaced in design grills but **not selected**. Kept as raw inspiration — reshape
freely for later biomes (4+). None are locked; mechanics here are sketches, not vetted against the
closed / single-condition rules or the "every status has an intrinsic effect" principle.

---

## The Overgrowth — species not chosen

| Species | Affinity lean | Sketch mechanic |
|---|---|---|
| **Thornvines** | Endurance | Retaliation wall — `on-damage-taken → hit back`, stacks; more of them = more painful to touch. |
| **Mantises** | Instinct | Ambushers — act **first** / punish acting before the enemy. *(Turn-order — now built; reusable.)* |
| **Nectarhunters** | Vitality | Sustain — heal when dealing damage; a bruiser member grows stronger while healthy. |
| **Herd-grazers** | Endurance | Protect-the-weak — a guardian provokes/redirects; herd members buff each other's Defence. |
| **Wasps** | Violence / Wit | Mark & sting — apply **Vulnerability** (mark), a finisher hits Vulnerable for bonus. |
| **Carapace beetles** | Endurance | Defend-engine — `on-defend → team Defence`; a counter-puncher hits harder while defending. |
| **Seed-poppers** | Vitality / Violence | Death-value — **burst on death** (damage/buff); siblings gain when one dies. |
| **Warblers (songbirds)** | Instinct | Tempo — grant permanent **+Speed**; a payoff scales off Speed advantage. |
| **Colony ants** | Wit / Violence | Caste split — **workers** enable (buff/heal), **soldiers** pay off (attack). |

## Glimmerdark — species not chosen

| Species | Affinity lean | Sketch mechanic |
|---|---|---|
| **Anglers (lurefish)** | Endurance | Bioluminescent bait — Lure `on-provoke → defending`, Snapper `on-damage-taken → retaliate`. *(Overlaps Snapjaws.)* |
| **Foxfire** | Wit | Dazzle-blind — `on-attack → Weaken`; payoff `+% to Weakened`. |
| **Geodes (crystalbacks)** | Endurance | Defend + reflect — `on-defend → team Defence`; a member `on-damage-taken → reflect a portion`. |
| **Beacon-corals** | Vitality | Light-healers — `on-round-end → heal allies`; a member scales while allies are healthy. *(Good Vitality option if a biome needs one.)* |
| **Duskswarm (moths)** | Instinct | Evasion in numbers — **count-scaling** +Speed per living swarm-mate. *(Overlaps Swarmhive.)* |
| **Palewurms** | Vitality / Endurance | Burrow-regen — `on-round-end → Regen`; deep tanky sustain. *(Overlaps Treants.)* |
| **Flarewings** | Violence / Instinct | Ramping alpha — high Attack; `on-attack → permanent self +Attack stack` (snowballs each swing). |
| **Nightveils** | Wit / Endurance | Darkness opener — `on-fight-start → Weaken all enemies`; a payoff capitalizes on a blinded board. |
| **Chimecolony** | Wit / Vitality | Resonance buff — `on-cast → buff all allies`; a Beneficiary scales off active buff count. |

## Rotcap Hollow — species not chosen

| Species | Affinity lean | Sketch mechanic |
|---|---|---|
| **Blightcaps** | Wit | Setup → nuke — `on-cast → Vulnerability`; finisher `+% to Vulnerable`. |
| **Parasitics (cordyceps)** | Wit / Violence | Infest & erupt — apply **Infest**; an Infested enemy that dies **bursts** into its own side. *(Needs a new Infest status.)* |
| **Moldwalls** | Endurance | Rot-fortress — stack permanent +Defence + Regen; `on-damage-taken → Poison the attacker`. |
| **Deathcaps** | Wit | Stack-the-rot — pile Poison; payoff `+% per DoT stack on target`. *(Twin of Sporecloud's payoff.)* |
| **Symbiotes (lichen)** | Vitality / Endurance | Pairing — heals/buffs a paired ally, scales while paired. *(Wants adjacency → biome 4+; reframe to "lowest-HP ally" to ship earlier.)* |
| **Bloomrot** | Vitality | Grow → burst — `on-round-end → +stack`; at max, bursts a team heal. *(Overlaps Glowflies charge-release + Treants growth.)* |
| **Gasbloats (puffballs)** | Endurance / Violence | Detonate — `on-death → AOE Poison burst`; rewards allies dying (trade bodies). *(Twin of Myconet.)* |
| **Manglers (toothed fungi)** | Violence | Armor-shred — high Attack; `on-attack → permanent −Defence on target` (uncapped grind-down). |
| **Mireshamblers (bog-fungus)** | Endurance / Instinct | Slow the field — apply **Web** broadly + `+% to enemies acting after you`. *(Reuses Web / turn-order.)* |
